CriptoRadar

CriptoRadar — Crypto-Tracking SaaS

A full-stack SaaS that tracks cryptocurrency prices in real time, with watchlists, price alerts and an AI market-analysis feature. Built solo: Supabase auth (email + Google OAuth) with row-level security, subscription payments via HMAC-verified webhooks, and a serverless Edge Function that emails alerts on a cron schedule.

SummaryAI

SummaryAI — AI Text & Audio Summarizer (Android)

A native Android app that summarizes text and voice recordings using AI. Pick a summary style (short, normal, detailed); for audio it transcribes the recording first, then summarizes it. Built with Jetpack Compose and a Node.js/Express backend that calls LLMs (GPT-4o) through OpenRouter, handling file uploads and transcription server-side.

Kotlin Jetpack Compose Retrofit Node.js Express OpenRouter / LLM

Fuel Calculator

Aviation Fuel Calculator (iOS & Android)

A cross-platform app for airline ground operations that reconciles aircraft fuel. It converts between pounds, gallons and litres using fuel density, computes the uplift across multiple tanks, and checks the discrepancy against fleet-specific tolerances (A320, B737, B777 and more) — with a step-by-step "fill helper" that shows every formula. Per-airline calculators (Delta, United, Air Canada…).

React Native Expo JavaScript EAS Build Cross-platform

Accident Report — Incident Reporting System

A complete full-stack system for workplace incident reporting, running on web, Android and iOS from a single codebase.
